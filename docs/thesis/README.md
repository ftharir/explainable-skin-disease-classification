# Thesis

The bachelor's thesis behind this project: *Facial skin image analysis for identifying several skin conditions using deep learning and explainability methods.*

| Language | Files |
|---|---|
| English | [`en/thesis-en.pdf`](en/thesis-en.pdf) · [`en/thesis-en.docx`](en/thesis-en.docx) |
| Persian (original language) | [`fa/thesis-fa.pdf`](fa/thesis-fa.pdf) · [`fa/thesis-fa.docx`](fa/thesis-fa.docx) |

Personal and institutional information was removed from both editions (names, university, supervisor, acknowledgements, file metadata). The English edition is a translation of the Persian text; equations and figures that contained Persian text were redrawn.

**Please read [NOTE_ON_NUMBERS.md](NOTE_ON_NUMBERS.md):** the headline results agree with the repository (accuracy 80%, macro-F1 ≈ 0.80), but some detailed numbers in the thesis tables differ from what the checkpoint and log in this repository reproduce.

## Contents

1. **Introduction**: problem statement, objectives, research questions, hypotheses and innovation
2. **Theoretical foundations and literature review**: CNNs, ResNet, transfer learning, explainable AI, Grad-CAM, research gap
3. **Methodology**: dataset, preprocessing, model and training settings, Grad-CAM, the Streamlit demo
4. **Findings**: training analysis, classification report, confusion matrix, Grad-CAM before and after improvement, error analysis
5. **Conclusions and recommendations**
